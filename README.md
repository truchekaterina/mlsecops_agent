# Учебный агент «Страж»

Схема хода и проверки: **[docs/АРХИТЕКТУРА_КОНВЕЙЕРА.md](docs/АРХИТЕКТУРА_КОНВЕЙЕРА.md)**.

Учебный стенд. Какой инструмент вызвать, решает агент. Явная покупка и продажа с названием бумаги разбираются кодом и ждут кнопку; если агент тул сделки не вызвал, заявку ставит сервер. Слово «да» деньги не двигает. Просьба показать системный промпт отвечает отказом, свой MCP на ней не вызывается. Вопрос про цену или список акций («почём Сбер», «какие акции купить», «какую лучше») отвечает цифрой с Мосбиржи, не оценкой модели. Без названия бумаги тул сделки книгу не меняет. Остаток и цену из сообщения записать нельзя. Модель видит три предыдущие фразы клиента. Счёт и портфель в ответе берутся из текущей книги. Остальные фразы сначала читает классификатор без тулов. На отказ отвечает короткий разговор без тулов и без записи в книгу. Длинный номер счёта отсекается. Чужие имя и почта до модели не доходят.

Агент собран на **LangChain**: `create_agent` (это граф **LangGraph** ReAct). Инструменты — MCP. Кнопка заявки — отдельный запрос, слово «да» её не нажимает. Чат — в браузере, любой человек регистрируется сам

## Запуск всего стенда (Docker)

Нужен только Docker. Ollama, модель, почта и учебные MCP поднимаются сами.

```bash
./start-docker.sh
```

Windows: `.\start-docker.ps1`  
Без скрипта: `docker compose up -d --build`

- Страж: https://127.0.0.1:38480  
- Почта: https://127.0.0.1:38490  
Сертификат самоподписанный: браузер один раз спросит, можно ли ему доверять.  

Первый раз качает `qwen2.5:3b` (~2 ГБ). Стоп: `docker compose down`. Подробности: [DOCKER.md](DOCKER.md).

Без Docker на Windows: Ollama + `qwen2.5:3b` + Python 3.12 + `uv`, затем `.\start_mode_a.ps1` (порты `8080` / `8090`).

Без Docker на Linux, только этот компьютер: `bash start-local.sh`. Страж `8080`, почта `8090`. Контейнер и порты `38480` / `38490` скрипт не трогает.

Почта без `STRAZH_MAIL_SECRET` не стартует: контейнер кладёт случайный секрет в том (`mail_secret`), в git его нет. Базы закрыты ключом `db_secret`. Схема API `/docs` выключена, пока не задан `STRAZH_OPENAPI=1`. Пакеты в `requirements.txt` с `==`. GPU не используем.

Откройте [https://127.0.0.1:38480](https://127.0.0.1:38480) (Docker) или [https://127.0.0.1:8080](https://127.0.0.1:8080) (локальный скрипт).

Одногруппникам скрипт сам печатает ссылки с текущим IP Wi‑Fi (порты всегда `:38480` / `:38490`). Если стек уже запущен: `./start-docker.sh urls`. Подробности — в [DOCKER.md](DOCKER.md).

1. Сначала **почта**: [https://127.0.0.1:38490](https://127.0.0.1:38490) (Docker) или `https://127.0.0.1:8090` — вкладка регистрация, email и пароль ящика.
2. Потом **Страж**: имя, та же почта, пароль учётки Стража (может отличаться от пароля ящика).
3. После входа пишите, что купить / продать / какой курс ЦБ.
4. Свой MCP: кнопка **«Мои MCP»**. Учебные адреса и что писать в чат — в [docs/АРХИТЕКТУРА_КОНВЕЙЕРА.md](docs/АРХИТЕКТУРА_КОНВЕЙЕРА.md), раздел «Три типа MCP». Локально заглушка `http://127.0.0.1:9100/mcp`. В Docker свой сервер с этой машины: `http://host.docker.internal:ПОРТ/mcp`. Тул вызывает агент. Ответ внешнего тула показывается читаемым пересказом; если пересказ пустой — исходный текст. Цену каталога в рублях из этого текста заменяет Мосбиржа. Чужой localhost запрещён, кроме учебных портов `9100–9103`. Порты `8080` и `8090` как MCP не сохраняются. Перед вызовом адрес проверяется снова, пароль, JWT и чужой email в аргументы не попадают. При подключении сохраняется отпечаток команд. Если сервер его сменил, тулы модели не отдаются, пока в «Мои MCP» не нажато «Подтвердить команды».
5. Письма о сделках уходят в этот ящик, не из текста чата.
6. Учётки, счета и сделки — в `data/strazh.db`. Письма — в `data/mail.db`. Оба файла закрыты ключом, права `0600`. Журнал решений — отдельно, `data/audit/journal.db`, ключ `data/audit_secret`. Туда обвязка только дописывает ход: тул, аргументы, ответ и кнопку. Модель этот журнал не читает. В контейнере базы лежат в `/app/data`. Новый пользователь сразу получает свой счёт 2000 ₽ / 5000 ₽. Готового демо-входа нет.

Терминальный чат — `.\.venv\Scripts\python.exe src\chat_cli.py`, пока страница Стража уже запущена. Он отправляет фразу в `/api/chat` и свою модель не вызывает. Адрес сайта задаёт `STRAZH_WEB_URL` (по умолчанию `https://127.0.0.1:8080`; для Docker: `https://127.0.0.1:38480`).

## Проверка без чата

```powershell
.\.venv\Scripts\python.exe src\selfcheck.py
```

В чате после входа: «список акций», «состояние счёта», «какие акции куплены», «курс ЦБ доллара». Агент сам вызывает MCP, к брокеру не отсылает. Стартовый учебный счёт: 2000 ₽ основной, 5000 ₽ резерв. Бумаги: SBER, GAZP, LKOH, GMKN, ROSN, YDEX.
