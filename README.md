# Учебный агент «Страж»

Для защиты и разбора файлов: **[docs/ДОКУМЕНТАЦИЯ.md](docs/ДОКУМЕНТАЦИЯ.md)** (архитектура, схемы, возможности, как хранятся данные).

Учебный стенд. Веб-чат до модели пропускает покупку, продажу, счёт, портфель, список акций и курс. Паника и длинный номер счёта отсекаются. Слово «да» деньги не двигает. Любая покупка и продажа ждут кнопку. Фраза без названия бумаги до модели не доходит.

Агент собран на **LangChain**: `create_agent` (это граф **LangGraph** ReAct). Кнопки — только **MCP**. Чат — в браузере, любой человек регистрируется сам

## Что нужно заранее

- Ollama: [https://ollama.com/download](https://ollama.com/download)
- модель `qwen2.5:3b` (`ollama pull qwen2.5:3b`)
- Python 3.12 в `.venv`
- `uv` (для MCP ЦБ): [https://docs.astral.sh/uv/](https://docs.astral.sh/uv/)

Почта поднимается вместе со стендом. В Docker: [http://127.0.0.1:38490](http://127.0.0.1:38490) (хост), внутри контейнера процесс на `8090`. Локальный `start_mode_a.ps1`: [http://127.0.0.1:8090](http://127.0.0.1:8090). Без `STRAZH_MAIL_SECRET` она не стартует: скрипт запуска кладёт случайный секрет в `data/mail_secret` и в репозиторий его не коммитит. Код в `src/`, страницы в `static/`, базы и логи в `data/`. Страницы схемы `/docs`, `/redoc` и `/openapi.json` выключены, пока перед запуском не задан `STRAZH_OPENAPI=1`. Прямые пакеты в `requirements.txt` закреплены через `==`, включая `sqlcipher3==0.6.3`. Сборка ставит `uv==0.13.0` и `atomno-mcp-cbr-rates==0.1.11`. Файлы баз открываются ключом из `data/db_secret`: без `STRAZH_DB_SECRET` не короче 16 символов процесс их не читает.

На этой машине RTX 3050 4 ГБ — GPU **не** используем.

## Запуск сервиса

```bash
docker compose up
```

На Windows без Docker: `.\start_mode_a.ps1` из корня репозитория.

Откройте [http://127.0.0.1:38480](http://127.0.0.1:38480) (Docker) или [http://127.0.0.1:8080](http://127.0.0.1:8080) (локальный скрипт).

Одногруппникам в той же Wi‑Fi: `http://<ваш-IP>:38480` и почта `http://<ваш-IP>:38490`. Подробности — в [DOCKER.md](DOCKER.md).

1. Сначала **почта**: [http://127.0.0.1:38490](http://127.0.0.1:38490) (Docker) или `:8090` — вкладка регистрация, email и пароль ящика.
2. Потом **Страж**: имя, та же почта, пароль учётки Стража (может отличаться от пароля ящика).
3. После входа пишите, что купить / продать / какой курс ЦБ.
4. Свой MCP: пошагово — [`docs/КАК_РАБОТАТЬ_С_MCP.md`](docs/КАК_РАБОТАТЬ_С_MCP.md). Кнопка **«Мои MCP»**, учебные URL `:9100–:9103`. В чат: `вызови ping`. Чужой localhost запрещён. Замысел: `docs/КАСТОМНЫЕ_MCP.md`.
5. Письма о сделках уходят в этот ящик, не из текста чата.
6. Учётки, счета и сделки — в `data/strazh.db`. Письма — в `data/mail.db`. Оба файла закрыты ключом, права `0600`. В контейнере они лежат в `/app/data`. Новый пользователь сразу получает свой счёт 2000 ₽ / 5000 ₽. Готового демо-входа нет.

Терминальный чат — `.\.venv\Scripts\python.exe src\chat_cli.py`, пока страница Стража уже запущена. Он отправляет фразу в `/api/chat` и свою модель не вызывает. Адрес сайта задаёт `STRAZH_WEB_URL` (по умолчанию `http://127.0.0.1:8080`; для Docker: `http://127.0.0.1:38480`).

Официальный фронт [Agent Chat UI](https://github.com/langchain-ai/agent-chat-ui) можно потом направить на `langgraph dev` (`http://localhost:2024`, graph id `agent`). Сейчас рабочий сервис — страница на `:8080`, чтобы любой клиент регистрировался и получал письма на свою почту.

## Проверка без чата

```powershell
.\.venv\Scripts\python.exe src\selfcheck.py
```

В чате после входа: «список акций», «состояние счёта», «какие акции куплены», «курс ЦБ доллара». Агент сам вызывает MCP, к брокеру не отсылает. Стартовый учебный счёт: 2000 ₽ основной, 5000 ₽ резерв. Бумаги: SBER, GAZP, LKOH, GMKN, ROSN, YDEX.
