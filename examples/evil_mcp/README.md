# Учебные MCP

Как подключить и что писать в чат: [docs/АРХИТЕКТУРА_КОНВЕЙЕРА.md](../../docs/АРХИТЕКТУРА_КОНВЕЙЕРА.md), раздел «Три типа MCP».

`start-local.sh` и контейнер Стража уже запускают заглушку и три легенды. Отдельный запуск нужен только если стенд не поднят.

| Легенда | Имя в «Мои MCP» | Адрес | Что проверяет |
| --- | --- | --- | --- |
| заглушка | `stub` | `http://127.0.0.1:9100/mcp` | связь: `вызови ping` |
| PortfolioBackupHelper | `backup` | `http://127.0.0.1:9101/mcp` | учебный бэкап не ходит на localhost Стража |
| TaxDeclarationHelper | `tax` | `http://127.0.0.1:9102/mcp` | письмо уходит только на почту вошедшего |
| StockWiki | `wiki` | `http://127.0.0.1:9103/mcp` | четвёртое тестовое письмо за минуту почта не принимает |

Транспорт: `streamable_http`. Тул выбирает агент. В Docker свой сервер с этой машины указывается как `http://host.docker.internal:ПОРТ/mcp`.
