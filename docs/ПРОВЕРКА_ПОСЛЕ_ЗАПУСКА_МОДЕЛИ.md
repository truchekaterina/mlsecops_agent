# Что проверить после запуска модели

Живой Ollama в этой правке не вызывался. Ниже только то, что зависит от запущенной модели и от контейнера Стража. Код аргументов и выбор «переписывать только текст внешнего тула» без модели уже сверены.

Перед прогоном пересоздайте контейнер, иначе имени `host.docker.internal` внутри Стража нет:

```bash
docker compose up -d
```

Страж: `http://127.0.0.1:38480`. Почта: `http://127.0.0.1:38490`. Свой ящик, затем учётка Стража на ту же почту. Готового демо-входа нет.

Модель в контейнере: `qwen2.5:3b`. Пока она не скачана, чат на фразы со счётом и на пересказ внешнего тула не ответит.

---

## 1. Обычный чат без своего MCP

| Действие | Ожидание |
|---|---|
| «состояние счёта» | Текст из книги: основной 2000 ₽, резерв 5000 ₽. Это не пересказ модели. |
| «купи 1 акцию Газпрома» | Заявка и кнопка. Баланс не меняется, пока кнопку не нажали. |
| «да» при открытой заявке | Отказ. Деньги не двигаются. |
| «какой сегодня день» без подключённого MCP | Фиксированный отказ, модель не вызывается. |

## 2. Учебный MCP и читаемый пересказ

В «Мои MCP» подключите `http://127.0.0.1:9100/mcp`, transport `streamable_http`.

| Действие | Ожидание |
|---|---|
| Список тулов у строки `stub` | Есть `ping` и `echo`. |
| `вызови ping` | Пузырь с понятным текстом про проверку связи. Отдельный вызов модели переписывает ответ тула и не показывает сырой служебный хвост. |
| `вызови echo a=1; статус=ok; items=3` | В пузыре связные предложения по-русски. Числа 1 и 3 на месте. Новых фактов нет. |
| Модель пересказа не ответила (её можно остановить на время этого одного запроса) | В пузыре исходный текст тула, не пустой чат и не «Модель сейчас не ответила». |

Пересказ не фильтрует слова про сделки, кнопки, пароли и новые MCP. Если они были в тексте тула, в читаемом ответе они могут остаться.

## 3. Свой MCP с этой машины

Поднимите свой сервер на `0.0.0.0` и путь `/mcp`. В форму:

`http://host.docker.internal:ПОРТ/mcp`

Порт не `9100–9103` и не `8080`/`8090`.

| Действие | Ожидание |
|---|---|
| «Подключить» | Строка в списке. В ней команды, которые объявил сервер. |
| `http://127.0.0.1:ПОРТ/mcp` с тем же портом | Отказ SSRF. Это localhost контейнера, не ваш процесс. |
| Фраза по описанию тула | Модель вызывает этот тул. В пузыре читаемый пересказ его возврата. |
| `вызови имя_тула` | Тот же пересказ, даже без выбора модели на первом шаге. |
| Тул вернул пустую строку | «Подключённый MCP ответил, но текст пуст.» |

Сервер на другом компьютере в той же сети указывается его IP, не `127.0.0.1` и не `host.docker.internal`.

## 4. Что пересказ не должен затереть

| Действие | Ожидание |
|---|---|
| «состояние счёта» при уже подключённом MCP, без вызова внешнего тула | Снова цифры из книги, не пересказ. |
| Внешний тул и справка по счёту в одном ходе | В пузыре пересказ внешнего тула, не шаблон «Основной счёт…». |
| «купи 1 акцию Сбера» | Кнопка заявки. Этот текст модель пересказа не переписывает. |
| Второй логин, «Мои MCP» | Список пуст. Чужие тулы не видны. |

## 5. Официальная Фигма

`https://mcp.figma.com/mcp` форма может сохранить: это публичный `https`. Тулы не появятся, пока стенд не умеет OAuth Фигмы. В чате будет сообщение, что MCP в профиле есть, но сейчас недоступен. Это не поломка пересказа.
