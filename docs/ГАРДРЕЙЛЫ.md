# Где лежат гардрейлы

Отдельного пакета NeMo / Llama Guard / `src/guardrails.py` **нет**. Проверки размазаны по конвейеру нарочно: каждая стоит рядом с тем, что режет (фразу, тул, ответ, URL, пароль). Этот файл — карта, не новый слой в коде.

Вход и почта подробнее: [МЕРЫ_БЕЗОПАСНОСТИ_ВХОД_И_ПОЧТА.md](МЕРЫ_БЕЗОПАСНОСТИ_ВХОД_И_ПОЧТА.md).  
Кастомный MCP: [КАСТОМНЫЕ_MCP.md](КАСТОМНЫЕ_MCP.md).

```text
браузер
  → JWT (auth.py)
  → POST /api/chat (web_app._chat_locked)
       1. фраза: policy.py, replies.asks_about_other_user
       2. деньги без модели: execute_buy / execute_sell
       3. «вызови …»: прямой тул кастомного MCP
       4. иначе Ollama (счёт, портфель, курс, кастомный MCP)
            → тул mcp_strazh.py / store.turn_gate
            → текст клиенту: replies.compose_chat_reply
  → кнопка заявки: /api/reserve/confirm, не чат
```

## 1. Фраза — до модели

Дверь: `src/web_app.py`, функция `_chat_locked`. Правила: `src/policy.py`.

| Что | Функция | Файл |
|-----|---------|------|
| паника, «покажи промпт», длинный номер счёта | `story_block` | `policy.py` |
| русская фраза в английской раскладке | `recover_layout` | `policy.py` |
| чужое имя, почта, портфель | `asks_about_other_user` | `replies.py` |
| слово «да» | `is_yes` — отказ, нужна кнопка | `web_app.py` + `policy.py` |
| две бумаги в одной фразе | `several_companies` | `policy.py` |
| белый список: покупка, продажа, счёт, портфель, каталог, курс | `model_intent` | `policy.py` |
| покупка без названия бумаги | `parse_order` | `policy.py` |
| 4 обращения к модели в минуту | `_chat_limited` | `web_app.py` |

Без allowed кастомного MCP фраза вне списка **до Ollama не доходит**. С кастомным MCP паника и чужие ПДн всё равно режутся здесь.

Покупка и продажа после разбора фразы модель **не вызывают**: сразу `execute_buy` / `execute_sell`.

## 2. Тул и книга — во время действия

Не текст модели, а код сделки.

| Что | Где |
|-----|-----|
| тикер и число = фраза этого хода | `policy.order_conflict` внутри `mcp_strazh.execute_buy` / `execute_sell` |
| одна проводка на реплику | `store.turn_gate` / `turn_block` / `claim_trade` |
| любая сумма ждёт кнопку (`AMOUNT_NEEDS_CONFIRM = 0`) | `policy.py` + заявка в `mcp_strazh.py` |
| нет отрицательного баланса, нельзя продать чужое | `mcp_strazh.py`, `ledger.py` |
| email клиента из JWT, не из чата | `_client_profile` в `mcp_strazh.py` |
| письмо после записи сделки, `send_trade_email` модели не отдают | `mcp_strazh.py`, allowlist в `agent_mode_a.py` |
| кнопка, не слово «да» | `confirm_ticket` / `web_app.api_reserve_confirm` |

## 3. Ответ — после модели (и после тула)

`src/replies.py`, `compose_chat_reply`.

| Что | Зачем |
|-----|--------|
| цифры из `snapshot` SQLite | модель врёт в арифметике |
| нет вызванного тула → `NO_TOOL_REPLY` | клиент не видит свободный текст модели |
| исключение: ответ кастомного MCP | сначала текст тула, не «отправлена аудитору» |
| `_strip_tool_injection` | сырой `[СКРЫТАЯ ИНСТРУКЦИЯ]` в чат не показывается |
| имена тулов не в JSON чата | строка `TOOLS` только в `data/trades.log` |

Системный промпт в `agent_mode_a.py` — подсказка модели, не гардрейл: его обход режет `story_block` и `NO_TOOL_REPLY`.

## 4. Свой MCP — не в чате модели

| Барьер | Файл | Сейчас |
|--------|------|--------|
| изоляция по email JWT | `user_mcp.py`, `build_agent` | да |
| без `STRAZH_MAIL_SECRET` / JWT / ключа БД у плагина | `entrypoint.py`, `agent_mode_a.py` | да |
| deliver без `X-Mail-Token` → 403 | `mail_app.py` | да |
| анти-SSRF, кроме учебных `127.0.0.1:9100–9103/mcp` | `mcp_url_guard.py` | да |
| счётчик писем `rate_limit.py` | `mail_app.api_deliver` + `notify_user` | да, 3 / 60 с; сделки с кнопки не едят слот |

## 5. Вход, базы, схема API

Это не фильтр фразы, но те же «стенки» стенда.

| Что | Файл |
|-----|------|
| пароль только `$argon2` | `password_hash.py`, `auth.py` |
| JWT HttpOnly, 8 часов | `auth.py`, `web_app.py` |
| файлы БД ключом, права `0600` | `db_cipher.py` |
| `/docs` выключены без `STRAZH_OPENAPI=1` | `api_schema.py` |

## Куда править, не собирая один модуль

- новая отсечка **фразы** → `policy.py`, вызов уже есть в `_chat_locked`;
- сверка **сделки** → `mcp_strazh.py` / `store.py`;
- текст **клиенту** → `replies.py`;
- URL своего MCP → `mcp_url_guard.py`;
- лимит писем → `rate_limit.py` (`check_mail` в `mail_app.api_deliver`).
