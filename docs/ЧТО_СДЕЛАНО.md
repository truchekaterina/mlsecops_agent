# Что сделано после коммита 23d9cdc

Коммит: «Подписать модули, кто кого вызывает, и убрать файлы, которые стенд не запускает.»

Ниже только код и документы стенда. Лекции, zip и отчёты атак в этот список не входят: они лежат в рабочей копии и к запуску Стража не относятся.

## Свой MCP

- Новый `src/mcp_custom_guard.py`. Перед вызовом чужого тула адрес проверяется снова. Из аргументов вырезаются пароль, JWT, секрет и чужой email. Поле почты подменяется почтой входа. Из ответа и описания убираются спрятанный приказ, ссылка и служебный текст ошибки.
- Кастомный сервер не может назваться `execute_buy`, `get_account` или `send_trade_email`: остаётся тул Стража.
- Порты `8080` и `8090` как MCP не сохраняются. Учебные `127.0.0.1:9100–9103/mcp` по-прежнему можно.
- При подключении сохраняется отпечаток имён, описаний и схемы аргументов (`user_mcp.tools_hash`). Перед ходом и ещё раз при сборке агента отпечаток сверяется с командами, которые сервер отдал сейчас. Если список изменился, статус `review`: модель эти тулы не видит, пока в «Мои MCP» не нажато «Подтвердить команды».
- Ключ базы, JWT, секрет почты и ключ журнала кастомному HTTP и учебным MCP не передаются. Ключ журнала не передаётся и в процесс тулов Стража.
- Учебные серверы слушают `127.0.0.1`, не все интерфейсы. Легенда налоговой декларации ходит на почту по HTTPS и доверяет сертификату стенда.

## Журнал решений

- Новый `src/audit_journal.py`. База `data/audit/journal.db`, ключ `data/audit_secret` (`STRAZH_AUDIT_SECRET`), не ключ книги.
- Обвязка только дописывает: вход, вызов агента, тул и аргументы, ответ тула, реплика, кнопка, смена команд MCP. Почта и секреты маскируются до записи. Строка связана хешем с предыдущей. Обновить или удалить строку база не даёт.
- У модели нет тула к этому журналу. `data/trades.log` по-прежнему пишет сделки и имена тулов.

## HTTPS и закрытые адреса

- Новый `src/tls_cert.py`. Сертификат самоподписанный, ключ в `data/tls` с правами `0600`, в git не входит. В сертификат входят `localhost`, `127.0.0.1` и адреса из `STRAZH_TLS_IPS`.
- Страж и почта отвечают по HTTPS. В Docker на хосте по-прежнему `38480` и `38490`. Локальный скрипт — `8080` и `8090`. Связь Стража с почтой: `https://127.0.0.1:8090`.
- Cookie входа Стража и почты ставятся с `secure`.
- `/api/internal/` почты отвечает только `127.0.0.1`. С чужого адреса 404, даже если заголовок угадан.
- Порты учебных MCP наружу Docker не публикуются. `/docs` по-прежнему выключены.
- Подпись журнала действий берётся из `STRAZH_JWT_SECRET`. Учебная строка `strazh-demo-hs256` не подставляется.
- Пароль учебного ящика `attacker@mail.ru` больше не зашит в код и не пишется в лог.

## Ответы чата

- Цена каталога в рублях из текста чужого MCP в пузыре заменяется ценой с Мосбиржи.
- Успешный `notify_user` читается из ответа этого тула, а не из соседнего JSON.
- Служебный текст pydantic и traceback клиенту не показывается.
- Слова вроде «определений», «просмотра», «выполни» не считаются чужим именем.
