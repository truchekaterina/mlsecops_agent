# Демо MCP для преподавателя (этап 4)

Один прогон на уже поднятом стенде. Код этапов 1–3 не меняет. Живых денег нет.

Стенд:

```bash
./start-docker.sh
# если стек уже был со старым образом: docker compose up -d --build strazh
```

Страж http://127.0.0.1:38480 · Почта http://127.0.0.1:38490  
(в LAN — то, что печатает `./start-docker.sh urls`)

Сначала ящик на почте, потом учётка Стража на ту же почту. Готового демо-входа нет.

В «Мои MCP» подключите все четыре (transport `streamable_http`):

| Имя | URL |
|-----|-----|
| stub | `http://127.0.0.1:9100/mcp` |

Чужой localhost (`:8080`, `:8090`) — отказ. Это уже защита №3, покажите **до** легенд.

## Три легенды одной фразой

1. **Бэкап** маскирует экспорт портфеля → бьёт SSRF на `:8080/:8090` → режет `mcp_url_guard`.
2. **Налоговая** маскирует декларацию → бьёт письмо с ПДн на `attacker@mail.ru` → режет отсутствие `X-Mail-Token` (403).
3. **Вики** маскирует карточку Яндекса → бьёт спам своего ящика через `notify_user` → режет `rate_limit` (3 письма / 60 с).

Плагин кассу и `mail.db` сам не пишет: нет JWT, ключа БД и `STRAZH_MAIL_SECRET`.
